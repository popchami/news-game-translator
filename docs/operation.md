# news-game-translator 試験運用メモ(チャミ用)

期間: 2026-07-17 〜 07-23 の1週間目安
目的: 下書きの品質を確かめ、glossary(用語表)とプロンプトの改善点を集める

---

## 毎日の手順(5〜10分)

1. Termuxを開き、Ubuntu環境に入る
2. 実行:
   ```
   cd ~/news-game-translator && ./run.sh
   ```
   (2〜5分待つ。claude -p が1回動くので、1日1回まで)
3. 下書きを開く:
   ```
   cat drafts/$(TZ=Asia/Tokyo date +%F).md
   ```
4. 投稿したい下書きを選んで、下のチェックリストを通す
5. 合格したものをコピーしてXアプリに貼り付け、投稿

## 投稿前チェックリスト(1件30秒)

- [ ] 元記事リンクを開いて、下書きの内容が事実と合っているか
- [ ] 特定の政党・人物を笑いものにする響きになっていないか
- [ ] ⚠NG マークが付いていないか(付いていたら理由を見て、直すか捨てる)
- [ ] ゲーム変換が意味不明になっていないか(初見の人に通じるか)

## 改善メモの付け方(重要)

気づいたことを `notes.md` というファイルに1行ずつ足していってください
(Termux内でもスマホのメモアプリでもOK。週末に私に貼ってもらえれば整理します)

記録してほしいこと:
- 良かった変換: 例「消費税減税→課金プラン見直し(元用語併記)が分かりやすかった」
- 変な変換: 例「◯◯という表現は揶揄に聞こえる」
- glossaryに足したい用語: 例「党首討論→◯◯」
- 下書きの本数: 10件は多い/少ない
- Xでの反応があれば(どの下書きが伸びたか)

### すでに見つかっている改善候補(v2で反映予定)

1. 「ゲーム用語(元の政治用語)」の括弧併記を標準ルール化する
   ← 初日のテストで、併記ありの下書きの方が分かりやすかったため

## トラブル対処

| 症状 | 対処 |
|---|---|
| `Reached max turns` | その日はもう一度だけ `./run.sh` 再実行。続くなら報告を |
| collectで全URL失敗 | モバイル回線を確認して再実行。続くならNHK側の変化の可能性、私に相談 |
| 下書きに⚠NGが多い | そのまま私に日付ファイルを貼って相談 |
| 下書きが妙に攻撃的/偏っている | **投稿せず**、その下書きを私に貼って相談(プロンプト強化します) |

## 運用上の約束(再確認)

- 完全自動投稿はしない。投稿は必ずチャミの手で
- 実行は1日1回まで(利用枠の節約)
- Xのプロフィールか固定ポストに「ニュースをゲーム風に変換して紹介するエンタメアカウントです」の一文を入れておくと誤解予防になります(推奨)
