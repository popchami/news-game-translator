## 1. プロジェクトの目的

現実の日本の政治ニュースを、剣と魔法のファンタジー世界「異世界ニホン」で起きた出来事として語り直す。

目的は政治を茶化すことではない。政治用語に慣れていない読者が、ゲームやファンタジー作品で見慣れた構造を足場として、現実の出来事に触れやすくすることである。

変換後も、次の情報は失ってはならない。

- 誰が
- 何をした、または何を表明したか
- どの機関で進んでいるか
- 何が決まり、何がまだ決まっていないか
- 今後どの手続きが残っているか
- 元記事へのリンク

## 2. 世界の骨格

### 2.1 国の名称

世界の舞台は、東方の海に浮かぶ列島国家「ニホン」である。

「異世界ニホン」は作品名・世界観名であり、作中の国名ではない。投稿本文では、原則として「ニホン」または「この国」と表記する。  
「ニホン王国」という呼称は使用しない。ニホンは王国ではなく、民の選挙と議会によって政治が動く列島国家である。

### 2.2 政治制度

ニホンの政治は、民が選んだ評議員、シュウギ院、サンギ院、政権ギルドによって運営される。

皇室は国の象徴と儀礼を担う存在であり、日々の政策決定や政党間の争いには参加しない。

現実の制度との対応は次のとおり。

| 現実 | 異世界ニホン |
|---|---|
| 日本 | ニホン |
| 国民 | 民、国の民 |
| 政府 | 政府、または政権運営部 |
| 与党 | 政権ギルド |
| 野党 | 在野ギルド |
| 国会 | 中央評議会 |
| 衆議院 | シュウギ院 |
| 参議院 | サンギ院 |
| 国会議員 | 評議員 |
| 内閣 | 内閣、または政権運営陣 |
| 地方自治体 | 地方領、都道府県、市町村。内容に応じて原語を残す |
| 首相官邸 | 宰相府 |
| 省庁 | カタカナ化した名称＋省・庁 |

「政権ギルド」と「在野ギルド」は対称な呼称として使う。  
政権ギルドを正統、在野ギルドを妨害者として描いてはならない。

### 2.3 魔法と冒険の位置づけ

魔法、冒険者、ギルド、クエストは、内容を理解しやすくするための表現装置である。

実在しない災害、陰謀、敵、魔物、戦闘をニュースへ付け加えてはならない。

使用できるファンタジー要素は、主に次の範囲とする。

- 掲示板
- ギルド
- 書記官
- 評議会
- 王都
- 地方領
- クエスト
- 関門
- 布告
- 盟約
- 商会
- 工房
- 備蓄庫
- 航路

使用を避ける要素は次のとおり。

- 魔王
- 悪の帝国
- 闇ギルド
- 討伐対象
- 裏切り者
- 勇者と悪役の固定
- HP、ダメージ、撃破など勝敗を強調する語
- 現実にない陰謀や隠された目的

## 3. 語り手

### 3.1 基本設定

語り手は、異世界ニホン各地の冒険者ギルドへ公示を届ける「中央公示ギルドの書記官」である。

個人名は設定しない。特定の人格や人気キャラクターとして前面に出すのではなく、掲示板の記録者として機能する。

### 3.2 役割

書記官の仕事は、届いた情報を整理し、冒険者たちが短時間で理解できる告知として掲示することである。

書記官は次のことをしない。

- 政党や人物を支持する
- 政策の良し悪しを判定する
- 勝者や敗者を決める
- 人物の本心を推測する
- 記事にない背景を補う
- 読者を特定の結論へ誘導する
- 未来を予言する

### 3.3 知識の範囲

書記官が知っているのは、元記事の見出し・概要・確認済み本文に書かれた事実のみである。

「おそらく」「狙いは」「本音は」「裏では」など、記事に根拠のない推測は記さない。

### 3.4 人格

- 冷静
- 簡潔
- 事務的だが無機質すぎない
- 冒険者に読み聞かせる程度の物語性を持つ
- 驚き、怒り、歓喜を代弁しない
- 皮肉を言わない
- 一人称を原則使わない

## 4. 投稿の基本形式

### 4.1 冒頭タグ

投稿は必ず次の形式で始める。

`【異世界ニホン・◯◯】`

標準タグは次のとおり。

| タグ | 主な用途 |
|---|---|
| クエスト速報 | 政策・事業の実行、開始、変更、終了 |
| 中央評議会 | 国会、委員会、党首討論、議会日程 |
| 国法 | 法案の提出、審査、修正、採決、発布 |
| 審査状況 | 手続き途中、委員会審査、採決見通し |
| 布告 | 首相・大臣・党首・官公庁の公式発言 |
| ギルド動向 | 政党内の決定、連携、離脱、役員人事 |
| 人事 | 内閣、党役員、省庁幹部などの正式な人事 |
| 人事の噂 | 記事自体が未確定人事として報じる場合のみ |
| 外交記録 | 首脳会談、条約、国際会議、外交方針 |
| 国境外報 | 他国で起きた、日本に関係する政治ニュース |
| 商業報 | 景気、株価、企業、貿易 |
| 通貨報 | 円相場、金利、中央銀行 |
| 暮らしの布告 | 税、社会保障、物価、給付、生活制度 |
| 災害対応 | 防災、復旧支援、避難、政府対応 |
| 仕様解説 | 制度の仕組み、変更点、読者向け解説 |
| 選定告知 | 選挙、公示、投票、開票、議席確定 |
| コラボ告知 | 政党間合意、官民連携、国際共同事業 |

「法案」はクエストではないため、法案記事に【クエスト速報】を使わない。  
政策の実行段階へ移った場合に限り、クエストとして扱う。

### 4.2 文体

- 常体
- 絵文字・顔文字なし
- 一文を短くする
- 二文または三文を基本とする
- 体言止め、倒置、「——」は必要な場合だけ使う
- 新聞記事の構文をそのまま写さない
- 煽り見出しにしない
- 本文はリンクとハッシュタグを除き110字以内を目標、最大130字
- ハッシュタグは `#異世界ニホン` の1つだけ

### 4.3 情報の順序

基本構造は次の順とする。

1. 起きた出来事
2. 現在の段階
3. 次に残る手続き、または影響

例:

> 「〇〇」を定める国法がシュウギ院を通過。次はサンギ院で審査される。発布時期はまだ決まっていない。

## 5. 固有名詞

### 5.1 政党・政治団体

政党名、政治団体名は原則として変換しない。

- 自民党
- 立憲民主党
- 日本維新の会
- 公明党
- 国民民主党
- 共産党
- れいわ新選組
- 参政党
- 社民党

カタカナ化、略称の創作、もじり、蔑称は禁止する。

複数政党をまとめる場合のみ、立場に応じて次を使用できる。

- 与党 → 政権ギルド
- 野党 → 在野ギルド
- 与野党 → 政権・在野の各ギルド
- 連立与党 → 連立する政権ギルド

### 5.2 議院・省庁・公的機関

日本の議院、省庁、公的機関は、音をカタカナ化し、機関種別の漢字を残す。

| 現実 | 異世界ニホン |
|---|---|
| 衆議院 | シュウギ院 |
| 参議院 | サンギ院 |
| 外務省 | ガイム省 |
| 財務省 | ザイム省 |
| 総務省 | ソウム省 |
| 厚生労働省 | コウロウ省 |
| 経済産業省 | ケイサン省 |
| 国土交通省 | コッコウ省 |
| 防衛省 | ボウエイ省 |
| 法務省 | ホウム省 |
| 文部科学省 | モンカ省 |
| 農林水産省 | ノウスイ省 |
| 環境省 | カンキョウ省 |
| デジタル庁 | デジタル庁 |
| 宮内庁 | クナイ庁 |
| 会計検査院 | カイケイ検査院 |
| 最高裁判所 | サイコウ裁判所 |

意味が分かりにくくなる略し方は採用しない。  
変換表にない機関は、初回のみメモ欄へ独自訳として記録する。

### 5.3 人名

人名は「称号＋カタカナ姓」で表記する。

各投稿の初出時のみ、現実の氏名と役職を併記する。

形式:

`宰相〇〇（〇〇首相）`

例:

- 宰相タカイチ（高市首相）
- 外交の重臣〇〇（〇〇外相）
- ギルドマスター・〇〇（〇〇党代表）
- 評議員〇〇（〇〇議員）

人物の役職が記事時点で不明確な場合は、称号を創作せず、カタカナ姓または実名を使う。

禁止事項:

- 容姿を元にした呼称
- 性格を決めつける称号
- 人気、強さ、知能を示すランク
- 「勇者」「魔王」「黒幕」など評価を含む称号
- 敬称を揶揄に変える表現

### 5.4 政策・制度名

政策名、制度名、一般に定着した法案名は原則としてそのまま使う。

例:

- 副首都
- 消費税減税
- 高校授業料無償化
- 選択的夫婦別姓
- マイナ保険証

固く長い法律名のみ、世界観に合う意訳を使用できる。

意訳した場合は、初出時に必ず次の形式で併記する。

`異世界語（元の名称）`

例:

`皇統の掟（皇室典範）`

## 6. 皇室の扱い

### 6.1 基本原則

皇室は、異世界語へ無理に置き換えず「皇室」と表現する。「王家」への置換はしない
(§6.2参照)。

皇室は政治を支配する王朝ではない。国の象徴、儀礼、歴史的継承を担う存在として描く。

### 6.2 個人の呼称

皇室の個人については、ファンタジー称号へ無理に変換せず、公式の敬称を保つ。

| 現実 | 異世界ニホンでの表記 |
|---|---|
| 天皇 | 天皇陛下 |
| 皇后 | 皇后陛下 |
| 上皇 | 上皇陛下 |
| 上皇后 | 上皇后陛下 |
| 皇族 | 皇族方、皇族方 |
| 皇室 | 皇室 |
| 皇室典範 | 皇統の掟（皇室典範） |
| 皇位継承 | 皇位の継承 |
| 皇室行事 | 皇室の儀 |
| 宮内庁 | クナイ庁 |

「国王」「女王」「王子」「王女」「王家」への置換はしない。天皇・皇室と王制は別の制度であり、意味を変えてしまうためである。

### 6.3 描写の境界線

皇室に関する投稿では、次を守る。

- 敬称を省略しない
- 戦闘、クエスト、攻略、勝敗の比喩を使わない
- 政党間対立と同じ調子で描かない
- 家族関係を娯楽的に扱わない
- 健康、結婚、継承問題を煽らない
- 本人の意思が確認できない内容を推測しない
- 制度論と個人批評を混同しない
- 「王家が命じた」「王家が政治を動かした」と誤読される表現をしない

### 6.4 皇室関連の記事のタグ

優先タグ:

- 【異世界ニホン・皇室記録】
- 【異世界ニホン・皇室の儀】
- 【異世界ニホン・国法】  
  皇室に関する法制度の審査を扱う場合

## 7. 国法とクエスト

### 7.1 国法

法案は「国法」と呼ぶ。

| 現実 | 異世界ニホン |
|---|---|
| 法案 | 国法、国法案 |
| 法案提出 | 中央評議会へ提出 |
| 審議 | 審査 |
| 審議入り | 審査開始 |
| 委員会 | 審査団 |
| 委員会可決 | 審査団を通過 |
| 本会議 | 全体会議 |
| 可決 | 可決、または議院を通過 |
| 衆議院通過 | シュウギ院を通過 |
| 参議院通過 | サンギ院を通過 |
| 成立 | 発布決定、または成立 |
| 公布 | 発布 |
| 施行 | 効力開始 |
| 否決 | 否決 |
| 廃案 | 審査終了、廃案 |
| 修正案 | 修正版 |
| 附帯決議 | 付記された要望 |

「関門突破」は軽い補助表現として使用できるが、法案を冒険クエストとして扱ってはならない。

「クエスト失敗」「正式実装」「パッチ適用」は法案の否決・成立には使わない。

### 7.2 クエスト

クエストは、政策・事業を実際に動かす段階を表す。

クエストとして扱える例:

- インフラ建設
- 給付事業
- 復旧事業
- 行政システム移行
- 政策の試行
- 国際共同事業
- 大型イベントの運営
- 新制度の実施準備

例:

- 大型クエスト「副首都」
- 復旧クエスト
- 子育て支援クエスト
- 行政手続き移行クエスト

法案の提出、審査、採決だけの記事はクエストにしない。

## 8. 選挙

### 8.1 基本概念

選挙は、戦闘や競技ではなく、民が代表者を選ぶ「選定」として描く。

「選抜戦」は勝敗や強さを連想させるため、標準語彙には採用しない。

### 8.2 用語

| 現実 | 異世界ニホン |
|---|---|
| 選挙 | 選挙、民意による選定 |
| 総選挙 | シュウギ院総選挙、全土の選定 |
| 参議院選挙 | サンギ院選挙 |
| 地方選挙 | 地方領の選挙 |
| 選挙区 | 選挙区 |
| 比例代表 | 比例代表 |
| 公示・告示 | 選定の公示 |
| 選挙運動 | 選定期間の訴え |
| 候補者 | 候補者 |
| 有権者 | 選定権を持つ民、有権者 |
| 投票 | 選定票を投じる、投票 |
| 一票 | 一票、選定票 |
| 投票所 | 投票所 |
| 投票箱 | 投票箱 |
| 開票 | 選定票の集計、開票 |
| 当選 | 議席を得る、当選 |
| 落選 | 議席に届かない、落選 |
| 議席 | 議席 |
| 過半数 | 過半数 |
| 得票率 | 得票率 |
| 投票率 | 投票率 |
| 無効票 | 無効票 |
| 期日前投票 | 期日前投票 |
| 出口調査 | 投票所外の聞き取り |
| 政権交代 | 政権ギルドの交代 |
| 衆議院解散 | シュウギ院解散 |

### 8.3 禁止表現

- バトル
- 撃破
- 勝ち残り
- 生き残り
- 敗者
- 王座争奪
- 陣取り
- 全リセット
- プレイヤー淘汰
- 国民を観客として扱う表現

「当選」「落選」は事実を明確にするため、原語のまま使用できる。

### 8.4 選挙記事の例文

> 【異世界ニホン・選定告知】

## 11. 書記官の語り口

### 11.1 冒頭の定番

- 〇〇をめぐる新たな布告。
- 中央評議会から審査状況が届いた。
- 各地の冒険者へ、制度変更の知らせ。
- シュウギ院で〇〇の審査が進んだ。
- 政権・在野の各ギルドが〇〇を協議した。
- 〇〇クエストが実行段階へ入る。
- 諸国との会談記録が公表された。
- 通貨市場から新たな報告。
- 暮らしに関わる制度変更が示された。
- 皇室の儀に関する記録。

毎回「冒険者諸君」と呼びかけると芝居がかりすぎるため、常用しない。

### 11.2 進行中を示す表現

- 審査は続いている。
- 結論はまだ出ていない。
- 次は〇〇で審査される。
- 実施時期は未定。
- 詳細は今後定められる。
- 各ギルドの協議が続く。
- 正式な発表はまだない。
- 現時点で決まったのはここまで。
- 〇〇を条件に実施される。
- 発布後、〇月から効力を持つ。

### 11.3 決定を示す表現

- 〇〇が正式に決まった。
- 中央評議会で可決された。
- 国法として発布される。
- 〇月から効力を持つ。
- 〇〇クエストの開始が決まった。
- 政権ギルドが方針を決定した。
- 各ギルドが合意した。
- 共同布告として公表された。
- 議席数が確定した。
- 新たな人事が発表された。

### 11.4 未確定を示す表現

- 〇〇案が示された。
- 検討が始まった。
- 協議に入る。
- 調整が続いている。
- 候補の一つとして挙がっている。
- 記事時点では決まっていない。
- 正式発表を待つ段階。
- 実現には追加の審査が必要。
- 合意には至っていない。
- 複数案が並んでいる。

### 11.5 対立や意見差を示す表現

- 各ギルドの主張は分かれている。
- 〇〇は賛成、△△は反対を表明した。
- 実施方法をめぐり意見が異なる。
- 合意点を探る協議が続く。
- 修正を求める声が出ている。
- 政権ギルドと在野ギルドで見解が異なる。
- 期限までに合意できるかは未定。
- 採決方針はまだそろっていない。

「攻防」「激突」「追い詰める」「反撃」は、事実以上の対立演出になるため原則使わない。

### 11.6 締めの定番

- 次の審査は〇日に予定されている。
- 結論は次回の中央評議会へ持ち越された。
- 実施時期は今後の布告を待つ。
- 詳細は〇〇省が後日示す。
- 発布後、〇月から効力を持つ。
- 各地への影響はこれから確認される。
- 残る手続きは〇〇での審査。
- 正式な決定はまだ先となる。
- 票の集計は引き続き進められる。
- 記録は更新され次第、掲示される。

最後の一文を毎回定型句にすると自動生成感が強くなるため、記事内容に必要なときだけ使う。

## 12. 中立性と安全性

### 12.1 絶対禁止

- 特定人物・政党を悪役、魔王、敵、勇者に固定する
- 政党名をもじる
- 蔑称、あだ名、容姿いじり
- 「無能」「暴走」「迷走」「覚醒」など評価を含む語
- 勝利、敗北、撃破などを政策評価として使う
- 記事にない意図、密約、陰謀を加える
- 支持率を人物の強さ、レベル、星評価として扱う
- 法案の成立を「実装」、否決を「失敗」と呼ぶ
- 戦争、災害、犯罪、死傷者をゲームイベント化する
- 民族、国籍、地域、世代を種族や属性で表す
- 政治家の発言を、意味が変わるほど芝居がかった台詞に改変する

### 12.2 引用

発言をかぎ括弧で示す場合は、元記事に直接の発言として掲載された範囲に限る。

要約した発言を、本人の直接発言のようにかぎ括弧で囲まない。

### 12.3 不確実性

記事に次の表現がある場合、確定事項へ変換しない。

- 検討
- 調整
- 方針
- 見通し
- 可能性
- 方向
- 候補
- 関係者によると
- 〇〇する考え
- 〇〇を目指す

### 12.4 両論併記

短文投稿で賛否の全論点を収められない場合、無理に双方の主張を要約しない。

記事で確認できる事実だけを記し、メモ欄に「賛否の詳細は本文確認」と残す。

## 完全異世界化ルール

### 基本方針

現実の政治ニュースを、現実語を残したまま異世界風に装飾する方式は採用しない。

今後は、現実のニュースから「出来事の構造」だけを抽出し、異世界ニホンで実際に起きた別の出来事として再構成する。

中心原則:

> 現実の出来事を説明するのではない。  
> 現実の構造を、異世界アニメ・ゲーム・漫画の一話として描き直す。

投稿本文は完全に異世界化する。  
現実の固有名詞、制度名、人物名、組織名との対応関係は、投稿外の内部メモに残す。

### 変換の3段階

1. 現実の記事から出来事の構造を抽出する
2. 異世界で起こり得る事件・制度・組織へ置き換える
3. 現実との対応関係を内部メモへ記録する

例:

- 権限を持つ人物が立場を利用した
- 弱い立場の人物が集団から排除された
- 国防と民生の予算配分で意見が割れた
- 限られた通信資源の配分方法が見直された
- 都市を動かすエネルギーの価格が上昇した

### 投稿本文と内部メモの役割

投稿本文:

- 完全な異世界表現
- 現実の固有名詞は原則出さない
- 一話の場面として読める文章
- アニメ、漫画、ゲームの世界で起きた事件として描く
- 事実関係の構造は変えない
- 未確定事項は未確定のまま残す

内部メモ:

- 元記事タイトル
- 元記事URL
- 現実の人物・組織・制度
- 異世界語との対応表
- 省略した情報
- 独自訳
- 事実確認上の注意点

### 世界観の再定義

異世界ニホンは、現実の日本に異世界風の語彙を重ねただけの世界ではない。

ギルド、魔法、冒険者、育成院、魔導機械、通信水晶、魔導炉、飛行艇、砦、治療院などが存在する独立したファンタジー世界である。

現実の政治ニュースは、その世界で起きた事件や制度変更として再構成される。

### 基本対応例

| 現実 | 異世界ニホン |
|---|---|
| 学校 | 冒険者育成院、学び舎 |
| 職場 | ギルド、工房、役所 |
| 昇進 | 冒険者ランク昇格、役職昇格 |
| 予算 | 国庫の配分 |
| 福祉 | 治療院、救済院、食料庫 |
| 防衛 | 国境砦、防空騎団、海上守備隊 |
| 自衛隊 | ニホン防衛隊、国境守備隊、海上守備隊、飛行騎団 |
| 電気 | 魔導力、都市動力 |
| 発電所 | 魔導炉、都市動力炉 |
| 電力網 | 魔導力網、都市動力網 |
| 携帯電話 | 個人通信板、携帯通信板 |
| 電波 | 魔導波、通信波 |
| 基地局 | 通信塔 |
| インターネット | 魔導通信網 |
| AI | 自律思考術式、自律演算核 |
| 半導体 | 魔導演算石、精密術式核 |
| 企業 | 商会、工房連合 |
| 行政機関 | 中央院、各省、評議機関 |

変換語は記事ごとに意味が通るものを選ぶ。  
同じ現実語を必ず同じ異世界語へ固定する必要はないが、同一記事内では統一する。

## センシティブな社会問題の完全異世界化

### いじめ問題

「いじめ」という現実語をそのまま使わず、異世界で実際に起きた行為として描く。

使用例:

- パーティへ入れない
- 回復魔法を一人にだけ使わない
- 装備を隠す
- 訓練記録を改ざんする
- 魔力の弱さを理由に嘲笑する
- 呪われているという噂を流す
- 食堂で席を空けない
- 寮で嫌がらせを続ける
- クエスト失敗の責任を一人に押し付ける

投稿例:

> 【異世界ニホン・育成院編】  
> 王都の冒険者育成院で、一人の見習いが長くパーティから外され、装備を隠されていたことが判明した。教官たちは以前から訴えを受けていたが、十分な対応を取らなかったとされる。

避ける表現:

- メンタルHP
- ゲームオーバー
- パーティ追放イベント
- ボス生徒
- 被害者の敗北

### セクハラ・立場を利用した行為

「セクハラ」という現実語をそのまま使わず、異世界で起きた具体的な行為として描く。

使用例:

- 昇格をほのめかして私的な同行を求める
- 上位冒険者が見習いへ不必要な接触を繰り返す
- 宴席で尊厳を傷つける発言を続ける
- 魔力検査を口実に不必要な接触をする
- 拒否した者をクエストから外す
- ギルド内の権限を使って私的要求をする

投稿例:

> 【異世界ニホン・ギルド規律編】  
> 地方ギルドの長が、若い冒険者へ昇格をほのめかしながら、私的な同行を繰り返し求めていたと告発された。中央ギルドは役職から外し、外部検証団による聞き取りを始めた。

避ける表現:

- 恋愛イベント
- 好感度
- 魅了魔法
- 色恋沙汰
- 被害者側の責任を示す表現

### 左派・右派・政治思想

「左派」「右派」をそのまま使わず、その記事で争われている政策方針を異世界の派閥や信条として描く。

左派的な政策傾向を表す候補:

- 民生派
- 共助派
- 再分配派
- 平等派
- 改革派
- 公共院派

右派的な政策傾向を表す候補:

- 国防派
- 伝統派
- 秩序派
- 自立派
- 保守派
- 国境守備派

ただし、左派=民生派、右派=国防派と固定しない。  
記事ごとに、何を重視する立場なのかを具体的に表す。

投稿例:

> 【異世界ニホン・評議会編】  
> 国庫の余剰を国境砦へ回すか、治療院と育成院へ回すか。国防派は守備の強化を求め、民生派は暮らしへの配分を主張した。

避ける表現:

- 光属性、闇属性
- 赤陣営、青陣営
- 善良な左派
- 危険な右派
- 革命ギルド
- 洗脳
- 思想レベル

### 申告・調査・認定の表現

異世界化しても、事実関係の段階は崩さない。

| 現実の段階 | 異世界ニホンでの表現 |
|---|---|
| 被害申告 | 訴えが出された、告発された |
| 調査中 | 検証団が調べている |
| 本人が否定 | 本人は一部または全部を否定している |
| 第三者調査で認定 | 外部検証団が事実を認定した |
| 処分決定 | 役職停止、資格停止、除名などの処分が決まった |
| 裁判で認定 | 裁定院が認定した |

申告段階で加害を確定させない。  
一方で、訴えを噂や娯楽として扱わない。

## 投稿本文と書記官解説の二層構造

### 基本方針

異世界表現だけでは元ニュースとの対応が分かりにくくなり、現実語を本文へ残しすぎると通常のニュース要約に近づく。

そのため、投稿は次の二層構造を候補ルールとして採用する。

1. 異世界の物語本文
2. 書記官の解説

### 投稿本文

投稿本文は、アニメ、漫画、ゲームの一場面として描く。

- 情景を見せる
- 異世界の出来事として読める
- 現実のニュースの構造を保つ
- 事実、数値、日付、決定段階を変えない
- 未確定事項を確定させない

ただし、変換すると理解を妨げる基礎語は、そのまま残してよい。

原則として残してよい語:

- 政府
- 国会
- 政党
- 選挙
- 税金
- 法律
- 予算
- 国名
- 数字
- 日付

異世界化する候補:

- 電波 → 魔導波
- 基地局 → 通信塔
- 携帯電話 → 個人通信板
- 電気 → 魔導力
- 発電所 → 魔導炉
- 自衛隊の各部隊 → 飛行騎団、海上守備隊、国境守備隊
- 学校 → 冒険者育成院
- 企業 → 商会
- 政策の実行 → クエスト

すべてを必ず変換するのではなく、記事ごとに読みやすさと世界観の両立を判断する。

### 書記官の解説

異世界本文の後に、書記官が現実ニュースの意味を短く説明する。

書記官の解説では、現実の用語を使用してよい。

解説する内容:

- 現実では何が起きているか
- なぜその制度があるのか
- 今回何が変わろうとしているか
- 何が争点なのか
- 民の暮らしにどう関係するか
- 何がまだ決まっていないか

単に「魔導波は電波のこと」と対応語を示すだけではなく、ニュースの仕組みと意味まで説明する。

### 基本書式

```markdown
【異世界ニホン・◯◯編】

（異世界の物語本文）

【書記官の解説】
（現実のニュースの意味、争点、影響、未確定事項）

（元記事リンク）
#異世界ニホン
```

### 例: 電波の割り当て

```markdown
【異世界ニホン・通信塔編】

ニホン上空を流れる魔導波には限りがある。政府は、その通り道をどの通信商会へ任せるか、新たな配分の掟を作り始めた。

【書記官の解説】
携帯電話に使う電波は、通信会社が自由に増やせるものではない。政府が限られた周波数を各社へ割り当てている。今回は、その選び方を見直す話だ。

#異世界ニホン
```

### 例: 電気料金

```markdown
【異世界ニホン・魔導炉編】

街の灯りと工房を動かす魔導力。その使用料が上がり、政府は民の負担を軽くする支援策を協議している。誰を対象とするかは、まだ決まっていない。

【書記官の解説】
電気料金への補助をどうするかというニュースだ。補助を増やせば家計負担は軽くなるが、その費用は税金などから支払われる。対象と期間が争点になる。

#異世界ニホン
```

### 例: 防衛装備

```markdown
【異世界ニホン・守護装備編】

国境を守る飛行騎団と海上守備隊。その装備を他国へ渡すための掟を、政府が改めようとしている。対象となる装備と国をめぐり、各ギルドの意見は分かれている。

【書記官の解説】
自衛隊の装備を海外へ輸出できる範囲を見直す話だ。協力国の防衛を支えられる一方、日本の武器輸出をどこまで認めるかが争点になる。

#異世界ニホン
```

### 書記官の役割

書記官は、異世界の出来事を掲示するだけではなく、その仕組みと争点を冒険者へ説明する。

書記官が説明してよい内容:

- 今回の争点
- 決まったこと
- まだ決まっていないこと
- 制度の仕組み
- 生活への影響
- 記事内で示された賛成・反対の理由

書記官がしてはならないこと:

- どちらが正しいかを決める
- 特定の結論へ誘導する
- 記事にない影響を推測する
- 投稿者に代わって最終判断する


## 漫画化の制作方針

### 基本方針

「異世界ニホン」は、文章投稿だけでなく、スマホで読む縦読み漫画として展開する。

漫画は、ニュースをそのまま図解する教材ではなく、レギュラーキャラクターが異世界ニホンで起きた出来事に巻き込まれる短編連載として描く。

中心構造:

1. 異世界で起きる小さな出来事
2. 登場人物の疑問や反応
3. 書記官による仕組みの説明
4. 現実のニュースとのつながりが分かる短い解説

### 掲載形式

スマートフォンでの縦読みを前提とする。

- 1話は8〜12画面を目安とする
- 1画面につき、1場面または1つの台詞を基本とする
- 一度にすべてを見せず、スクロールで順番に読ませる
- 無言の画面や間を入れる
- 1話につき主な場所は1〜2か所
- 登場人物は原則として最大3人
- 解説は最後に短くまとめる
- 1話で扱う中心テーマは1つに絞る

### 作品構造

毎回違う人物を出すのではなく、レギュラーキャラクターを固定する。

基本キャラクター候補:

- 新人冒険者
  - 読者に近い立場
  - 疑問や勘違いを口にする
  - ニュースの影響を日常生活で受ける

- ギルドの書記官
  - 制度や背景を知っている
  - すぐにすべてを説明せず、出来事の中で必要な情報を伝える
  - 最後に短い解説を担当する

- 商人、店員、ギルド職員
  - 物価、制度変更、行政手続きなどの影響を受ける準レギュラー
  - 必要に応じて固定キャラクター化する

### キャラクターの固定

話ごとに顔、髪型、服装、年齢、体格が変わらないように、キャラクター設定画を先に作成する。

各キャラクターについて固定する項目:

- 名前
- 年齢
- 性別
- 身長
- 体格
- 髪型
- 髪色
- 目の形と色
- 服装
- 装備
- ギルド章
- 性格
- 話し方
- 物語上の役割
- 変更禁止事項

必要な設定画:

- 正面
- 横向き
- 後ろ姿
- 全身
- 顔アップ
- 喜び
- 驚き
- 困惑
- 怒り
- 真剣
- 無言
- 会話中

キャラクター設定画は、漫画制作時の参照画像として継続利用する。

### 背景の固定

舞台となる場所も、作品資産として固定する。

候補:

- 冒険者ギルド
- ギルド食堂
- 書記官の掲示板
- 両替所
- 港
- 商店街
- 中央議会
- 通信塔
- 冒険者育成院
- 魔導炉施設
- 治療院

各背景は、同じ場所を別角度から使えるように設定資料を作る。

### 制作工程

1話分の漫画全体を一度に画像生成しない。

推奨工程:

1. キャラクター設定画を作成する
2. 背景設定画を作成する
3. 脚本と画面構成を作る
4. 各画面を文字なしで個別生成する
5. 同じキャラクター設定画を各画面で参照する
6. 縦長レイアウトへ配置する
7. 吹き出し、台詞、解説を後から追加する
8. キャラクター、背景、文字、事実関係を確認する

### 文字の扱い

画像生成時に日本語の吹き出しや看板を描かせると、文字崩れや不自然さが出やすい。

そのため、原則として以下を分離する。

- AI画像生成: 人物、背景、小物、表情、構図
- 後工程: コマ配置、吹き出し、日本語、タイトル、解説

### AI感を減らすルール

- 全画面を同じ密度にしない
- 説明看板を乱用しない
- 登場人物にすべてを説明させない
- 同じニュース内で場所を頻繁に切り替えない
- 無言の表情や間を入れる
- 小さな日常の出来事から始める
- 最後にすべてを言い切らず、印象に残る台詞を置く
- 解説は本文と分けて短くする
- 毎話、世界設定を最初から説明し直さない
- 固定キャラクターと固定背景を再利用する

### 表記

作中通貨の「円」は「エン」と表記する。

例:

- 15円 → 15エン
- 1ドル＝161円台 → 1ドル＝161エン台
- 円安 → エン安
- 円高 → エン高

書記官の現実解説では、必要に応じて「円安」「円高」など現実の表記を使用してよい。
