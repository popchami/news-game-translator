# 異世界ニホン変換表(チャミが自由に育ててよい)

## 組織・場所
| 現実 | 異世界ニホン |
|---|---|
| 政府・与党 | 王国運営 |
| 内閣 | 王国運営チーム |
| 野党 | 対抗ギルド(総称のみ。個別の政党名はそのまま) |
| 政党名(自民党等) | **変換しない** |
| 派閥 | 一門(例: 旧安倍派→旧アベ一門) |
| 国会 | 王国議会 |
| 衆議院 | シュウギ院 |
| 参議院 | サンギ院 |
| 委員会 | 審査団 |
| ◯◯省・庁 | カタカナ+省/庁(例: ガイム省、クナイ庁) |

## 役職・人
| 現実 | 異世界ニホン |
|---|---|
| 総理大臣 | 宰相 |
| 大臣 | ◯◯担当の重臣(例: 外務大臣→外交の重臣) |
| 党首・代表 | ギルドマスター |
| 議員 | 評議員 |

## 出来事
| 現実 | 異世界ニホン |
|---|---|
| 法案 | クエスト |
| 審議入り | クエスト受注 |
| 可決・通過 | 関門突破 |
| 成立 | 正式実装 |
| 否決 | クエスト失敗 |
| 内閣改造 | 運営チーム再編成 |
| 解散総選挙 | 全評議員の再選抜戦 |
| 選挙 | 選抜戦 |
| 予算案 | 王国の年間資金計画 |
| 増税/減税 | 税(貢納)の引き上げ/引き下げ |
| 記者会見 | 布告 |
| 党首討論 | ギルドマスター公開討論 |
| 支持率 | 民の評判 |
| 世論調査 | 民の声調べ |
| 国民会議 | 全ギルド合議(国民会議) |
| 皇室典範 | 王家の掟(皇室典範) |
